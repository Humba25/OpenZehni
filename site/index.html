Für Windows · Danach aktualisiert sich Zehni von selbst.

Was Zehni macht

  • 25 Lektionen von der Grundstellung bis zum Abschlusstest — alle Buchstaben, Zahlen und Satzzeichen der deutschen Tastatur.
  • Dazu zwei Module: Medienkompetenz (Passwörter, Quellen prüfen, Werbung erkennen, Bilder vom Computer erkennen) und Lernen lernen.
  • Spiele zum Üben, Abzeichen, ein Tagesziel — nichts davon ist Pflicht.
  • Mehrere Kinder an einem Rechner, jedes mit eigenem Fortschritt.

Was Zehni nicht macht

  • Kein Konto, kein Passwort, keine E-Mail-Adresse.
  • Keine Werbung, keine Käufe, nichts kostet etwas.
  • Nichts verlässt den Rechner. Der Lernfortschritt liegt in einer Datei auf dem eigenen Gerät. Zehni fragt nur nach, ob es eine neue Version gibt — sonst geht es nie ins Internet.
  • Keine Strafen, keine verlorenen Leben, kein „du hast heute noch nicht geübt".

Beim Installieren warnt Windows — das ist normal

Zehni hat kein gekauftes Zertifikat. Windows zeigt deshalb „Der Computer wurde durch Windows geschützt". Das heißt nicht, dass etwas nicht stimmt, sondern nur, dass niemand dafür bezahlt hat.

Wie man daran vorbeikommt, steht Schritt für Schritt in der Anleitung für Eltern. Dort steht auch, woran man erkennt, dass die Datei wirklich von hier stammt — denn eine Warnung wegzuklicken, ohne zu wissen warum, ist genau der Reflex, den Zehni Kindern abgewöhnen will.
