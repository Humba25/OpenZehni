# Platzhalter-Symbol

Die Symbole in diesem Ordner sind ein **Platzhalter**: ein weisses „Z" auf
blauem Grund, am 2026-09-12 erzeugt, damit der Build durchlaeuft.

Das Maskottchen der App ist eine Maus namens Zehni (`SPEC.md` 8.5). Sobald es
gezeichnet ist, gehoert es auch ins Symbol. Neu erzeugen mit:

```powershell
npx tauri icon pfad\zur\quelle.png
```

Die Quelldatei sollte quadratisch und mindestens 1024 x 1024 Pixel gross sein.
Danach `android/` und `ios/` wieder loeschen -- v1 ist Windows-only
(`SPEC.md` 3.1).
